AudioPowerSupply
================

Board Design: Andrew Martin, Acramonics, 2026

Circuit Design: Jake Rothmann

Overview
--------

This is a redesign of the PCB for Jake Rothmann's dual-rail power
supply for high quality audio work. The original board is rather large
and this version has been shrunk for use in my builds.

Note that the board suppors 18V-0-18V, 21V-0-21V, or 48V single rail.

The 21V-0-21V is designed as the best supply for NE5532s, but the
newer versions of these only support 18V-0-18V.

The 48V single rail is designed for microphone phantom power.

The component values in the schematic are for the 21V-0-21V version
(except where components are not present in that version, where they
are for the 18V-0-18V version). **Make sure to read the schematic
together with the BOM**
